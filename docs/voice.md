# 语音点歌和口令

[← 返回说明](../README.md)

对音箱说「小爱同学」之后说下面的话。程序每隔一两秒读取一次小爱的对话记录，听到要处理的话就先打断小爱自己的回答，再执行。所以小爱通常会先答半句、甚至先响一下它自己的内容，这个延迟避免不了。

**直接点歌（不用说关键词）**

说「播放 / 我想听 / 来一首 + 名字」，程序先查 NAS 曲库：

| 你说的是 | 结果 |
| --- | --- |
| 歌手，如「播放周杰伦的歌」 | 这位歌手在曲库里的全部歌曲 |
| 专辑名 | 整张专辑，按音轨顺序 |
| 歌名，或「歌手的歌名」 | 这首在前，后面接同文件夹的其他歌 |
| 自建歌单名或文件夹名 | 这个歌单 / 文件夹 |
| 曲库里没有的东西 | 交给小爱自己播，程序让出控制、不再发指令 |

这种说法只认**完全一致**的名字，免得误抢小爱自己的内容。歌手按歌曲文件里的「歌手」标签匹配，标签没填的歌进不了歌手队列。设置里有开关「曲库里有就由 NAS 播」。

**带关键词的口令（模糊匹配）**

| 口令 | 作用 |
| --- | --- |
| 播放歌曲 | 接着上次的队列播；没有队列就播放全部歌曲 |
| 播放歌曲 + 名字 | 歌手 / 专辑 / 歌名，允许不完全一致，如「播放歌曲周杰伦的晴天」 |
| 播放歌单 + 名称 | 自建歌单或文件夹名，如「播放歌单粤语」；「播放歌单收藏」播我的收藏 |
| 上一首 / 下一首 | |
| 暂停 / 继续 | 「继续」在 OH2P 上是从头重放当前这首，见「已知局限」 |
| 停止 | |
| 单曲循环 / 全部循环 / 随机播放 | |
| 加入收藏 / 取消收藏 | 针对正在播的歌 |

**播放中跟小爱说别的话**

- 调音量、问天气这类对话会把歌打断。程序等小爱答完，音箱没有自己恢复，就从头重放当前这首。设置里有开关「被对话打断后自动重放」。
- 说「别放了」「关掉音乐」这类话，按暂停处理，不会自动重放。
- 让小爱播曲库里没有的内容，程序让出控制；之后在网页点播放，是重新播放 NAS 的歌。

其他说明：

- 口令关键词可在「设置 → 语音口令」里改，多个说法用逗号隔开；设置页里有个「口令测试」输入框，只解析不执行。
- 「上一首 / 下一首 / 暂停 / 继续 / 停止 / 收藏」只在本程序正在播放或暂停时才生效，避免抢走小爱自己的功能。
- 长时间（默认 30 分钟）没有播放也没有口令时，读取间隔自动放慢到 5 秒，这时第一句话的反应会慢一点。
- 匹配是按文字来的，小爱把名字听成了同音的别的字就找不到。
- 不想让程序读取对话记录，可以在设置里关掉语音口令，只用网页 / App 控制。
